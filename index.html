إعدادات الباكب المتقدمة (كود Code.gs + index.html)

عشان الباكب يقدر يحفظ الكود نفسه: (1) فعّل "Google Apps Script API" من إعدادات حسابك مرة واحدة، و(2) ضيف صلاحية script.projects في appsscript.json (اسأل لو محتاج التعليمات بالتفصيل). استرجاع index.html أوتوماتيك اختياري ومحتاج GitHub Token — لو مش متسجل، هتاخد الملف جاهز تنزّله وترفعه يدوي.

مستويات الصلاحيات

عرّف أي عدد صلاحيات تحبه، وحدد لكل واحدة الأقسام المسموحة. الأقسام المتاحة:
reports, employees, rules, salary, users
مستندات (دقيق): docs_view, docs_add, docs_edit, docs_delete, docs_types_manage, docs_reports
نسخ احتياطي (دقيق): backup_create, backup_restore, backup_upload, backup_view
"أدمن؟ = نعم" معناها وصول كامل تلقائيًا لكل حاجة من غير ما تكتب الأقسام.
